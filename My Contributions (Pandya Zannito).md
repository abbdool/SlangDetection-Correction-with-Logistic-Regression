## My Contributions

I actively contributed to the implementation and development of the NLP-based slang classification and normalization system.

My responsibilities included:

* Implementing data preprocessing functions for text cleaning, normalization, and dataset preparation.
* Assisting in the development of the TF-IDF and character n-gram feature extraction pipeline.
* Contributing to the training and evaluation process of the Logistic Regression classification model.
* Implementing and testing parts of the hybrid processing workflow that integrates machine learning predictions with rule-based normalization.
* Assisting in the development and maintenance of the slang dictionary used for automatic text normalization.
* Participating in debugging, code optimization, and validation of prediction results.
* Supporting integration between the training pipeline and deployment pipeline to ensure consistent model behavior.
* Contributing to project documentation and technical presentations.

My contribution primarily focused on the NLP processing pipeline, machine learning implementation, and system testing phases of the project.
